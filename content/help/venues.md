## The venue directory

Open **Venues** from the main menu. The directory holds every venue PSG works in, with its details, tech spec, contacts and documents. The count at the top shows how many venues there are.

Search by name, city or address, or pick a type from **All types** (theatre, arena, outdoor, club, conference, hotel or other). Venues with a tech spec on file show a **Tech spec** badge.

The directory is shared. Tour stops and a production's venue are picked from it, so keep one entry per venue. See [Tour stops and advancing](/help/tour-stops-and-advancing).

## Adding a venue

1. Click **+ Add Venue**.
2. Enter the **Name** and pick a **Type**.
3. Add the **Address**, **City**, **Postcode**, **Phone**, **Email**, **Website**, **Capacity** and any **Notes**.
4. Click **Add Venue**.

## Importing from a tech spec

If you have the venue's technical specification, let the Hub do the typing.

1. Click **⬆ Import PDF / Word**, or drop one or more files onto it.
2. The Hub uploads the file and reads it. The button shows **Analysing with AI…**.
3. The new venue opens on its **Stage** tab with the details filled in.

If a venue with the same name is already in the directory, you are asked what to do: **Update existing venue**, **Create new venue** or **Cancel**. When you import several files, a summary shows how many worked.

## A venue's details

Click a venue to open it. The tabs are **Info**, **Stage**, **Rigging**, **LX**, **Sound**, **Facilities**, **H&S** and **Documents**.

### Info

- **Venue Details:** address, phone, email, website and capacity.
- **Technical Specification Document:** drop a tech spec PDF here, or click to upload one. The Hub reads it and fills in the Stage, Rigging, LX, Sound, Facilities and H&S tabs. Use **Download** to get the file back, or **Re-import** to load a newer version.
- **Contacts:** click **+ Add** to add someone at the venue, such as the technical manager, with their **Role**, **Phone**, **Email** and **Notes**. These stay with the venue for every show.
- **Drop-off details (from Night Run):** loading address, access times, vehicle limits, dock and parking. These come from the Night Run haulage app and cannot be changed here.

### Documents

Drag files onto the **Documents** tab, or click to upload. Any file type works: ground plans, section drawings, rigging plots or photos.

## Editing and deleting

Use **Edit** to change a venue's details. Click **Delete**, then **Yes, delete** to remove it. If Night Run uses the venue for haulage, you are warned first.
